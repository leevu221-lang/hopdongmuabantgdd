ĐIỀU 6: THỜI HẠN HỢP ĐỒNG

Hợp Đồng này tự động chấm dứt trong trường hợp sau:

6.1 Bên A không thực hiện nghĩa vụ thanh toán trong vòng 10 (mười) ngày làm việc kể từ Ngày Ký thì xem như Bên A không có nhu cầu mua hàng và Bên B không có nghĩa vụ giữ giá, hàng hóa cho Bên A. Khi đó, Hợp Đồng tự động chấm dứt. Trường hợp Bên A tiếp tục mua hàng thì Hai Bên phải ký lại Hợp Đồng mới; hoặc

6.2 Bên A đã thực hiện nghĩa vụ thanh toán: Hợp đồng được tự động chấm dứt sau khi Hai Bên hoàn thành các nghĩa vụ quy định tại Hợp Đồng. Riêng các điều khoản về bảo hành vẫn có hiệu lực cho đến khi hết thời hạn bảo hành theo quy định của nhà sản xuất hoặc nhà phân phối.

Nếu phát hiện vi phạm, bên bị vi phạm có quyền chấm dứt hợp đồng ngay lập tức, và bên vi phạm phải bồi thường mọi thiệt hại phát sinh.

8.2 Trong trường hợp xảy ra tranh chấp, hai bên cố gắng cùng nhau bàn bạc các biện pháp giải quyết trên tinh thần hòa giải, có thiện chí và hợp tác. Nếu vẫn không thể thống nhất cách giải quyết thì hai bên sẽ đưa vụ việc ra Tòa án có thẩm quyền giải quyết, toàn bộ chi phí xét xử do bên thua chịu.

8.3 Hợp đồng này được lập thành 02 (hai) bản, mỗi bên giữ 01 (một) bản có giá trị pháp lý như nhau.

Script & Hướng Dẫn Đẩy Mã Nguồn Lên GitHub

Chia sẻ phần mềm in ấn này lên GitHub để chạy online trực tiếp qua GitHub Pages hoàn toàn miễn phí, truy cập từ mọi thiết bị (Laptop, Điện thoại, Máy tính bảng)!

Bước 1

Tạo Repository Mới Trên GitHub

Truy cập vào github.com/new:

  • Repository name: in-hop-dong-a4
  • Chọn Public (để bật được GitHub Pages miễn phí).
  • Bấm nút Create repository.
Bước 2

Chạy Script Tự Động Trong Terminal

Mở Terminal trên máy tính Mac của bạn và chạy lệnh sau:

cd /Users/linhvu/.gemini/antigravity-ide/scratch/in-hop-dong-a4 chmod +x push_to_github.sh ./push_to_github.sh https://github.com/leevu221-lang/in-hop-dong-a4.git
Bước 3

Bật Chế Độ Website Trực Tuyến (GitHub Pages)

Sau khi push mã nguồn thành công:

  1. Vào Settings của Repo trên GitHub.
  2. Chọn mục Pages ở thanh menu bên trái.
  3. Tại Branch, chọn main và nhấn Save.
  4. Sau 1 phút, bạn sẽ có link web online dạng: https://leevu221-lang.github.io/in-hop-dong-a4/

Nội Dung Script Tự Động push_to_github.sh Sẵn Có Trong Dự Án:

#!/bin/bash
# Script tự động đẩy dự án lên GitHub
REPO_URL=$1

if [ -z "$REPO_URL" ]; then
  echo "Vui lòng nhập đường dẫn repository GitHub của bạn:"
  echo "Ví dụ: ./push_to_github.sh https://github.com/leevu221-lang/in-hop-dong-a4.git"
  exit 1
fi

git init
git add .
git commit -m "Khởi tạo công cụ Quản lý & In ấn Hợp đồng - Biên bản nghiệm thu A4 tone xanh pastel"
git branch -M main
git remote remove origin 2>/dev/null
git remote add origin "$REPO_URL"
git push -u origin main --force

echo "Đã đẩy mã nguồn lên GitHub thành công!"
